# Security

yactt treats its supply chain, install hook, and audit story as
first-class. For the full trust model, threat model, and
install-hook verification steps, see
[docs/security.md](docs/security.md).

## Reporting a vulnerability

Please use GitHub's
[private vulnerability reporting](../../security/advisories/new)
for this repository. Private reports are triaged within 7 days.

For a same-version replay or install-hook TOFU mismatch, see
[docs/security.md §2](../../docs/security.md#2-github-release-artifact-integrity)
for the steps to confirm and report.
